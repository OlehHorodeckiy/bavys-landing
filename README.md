# Бавись — оренда дерев’яних ігор у Львові

Сайт компанії, побудований на дизайн-системі референсу
[Calmlyss — Yoga Wellness Studio](https://dribbble.com/shots/27385676-Calmlyss-Yoga-Wellness-Studio-Website-Template):
та сама логіка сторінок, сітки, картки, кнопки й ритм секцій, але повністю новий контент — оренда ігор для подій.

React 19 + Vite. Шрифт — лише **Comfortaa** (300 — акцентні слова заголовків, 500 — текст, 700 — заголовки й кнопки).
Анімацій у першій версії немає навмисно.

## Запуск

```bash
npm install
npm run dev       # http://127.0.0.1:5173
npm run build     # статичний білд у dist/
npm run preview
```

Маршрути працюють через hash (`/#/games/velyka-dzhenga`), тож `dist/` можна викласти на будь-який
статичний хостинг без налаштування редиректів.

## Сторінки

| Маршрут | Сторінка |
|---|---|
| `#/` | Головна: hero з аркою ігор · про нас + цифри · каталог-превʼю · як це працює · чому ми · для яких подій · галерея · блог · CTA |
| `#/games` | Каталог з фільтрами (Корпоративи, Весілля, Дні народження, Фестивалі, Сімейні, Надворі, Для дітей) |
| `#/games/:slug` | Сторінка гри: hero з фактами · що це за гра · правила · для яких подій · деталі · галерея · бронювання · інші ігри |
| `#/gallery` | Галерея з фільтрами |
| `#/blog`, `#/blog/:slug` | Блог і стаття (деталі, фото, цитата, ігри зі статті, інші статті) |
| `#/about` | Про компанію |
| `#/contacts` | Контакти + форма заявки. `#/contacts?game=kubb` — гра вже обрана у формі |

Кожна сторінка має desktop (1440, перевірено також 1280 і 1920) та мобільну (390) версію.
На телефоні внизу завжди є панель «Ігри / Забронювати», а меню відкривається на весь екран.

## Структура

```
src/
  data/        контент: games.js, posts.js, gallery.js, site.js (контакти, навігація, події), media.js (фото)
  components/  дизайн-система: ui.jsx (кнопки, пігулки, заголовки, чипи, медіа), sections.jsx (картки та секції),
               Header, Footer, BookingForm, GameArt (ілюстрації ігор), Icon
  pages/       Home, Games, Game, Gallery, Blog, Article, About, Contacts, NotFound
  styles/      tokens.css (кольори, типографіка, відступи) → base → components → sections → pages
```

## Що замінити перед запуском

Частина контенту — чернетка, щоб показати структуру. Її треба замінити реальними даними:

- **Фото.** Зараз використано три фото з репозиторію (Дженга на банкеті, вежа на газоні, вежа окремо).
  Реальні фото з Figma: експортуйте у `assets/photos/`, додайте ключ у `src/data/media.js` і вкажіть його
  у `photo` / `hero` / `gallery` потрібної гри, у `gallery.js` або в статті. Ігри без фото показують
  ілюстровану плитку (`GameArt`) — вона автоматично зміниться на фото.
- **Каталог ігор** (`src/data/games.js`): список, характеристики й ціни. Ціни «від 900 / 650 / 1400 грн»
  перенесено зі старого лендингу, для решти ігор показується «розрахуємо під вашу подію».
- **Контакти** (`src/data/site.js`): телефон `+38 (000) 000-00-00`, e-mail, графік, посилання на соцмережі.
- **Цифри** на головній (32 набори, 120+ подій, 24 год) — зі старого лендингу, варто перевірити.
- **Статті блогу** (`src/data/posts.js`) — демонстраційні тексти.

## Заявки на пошту

Форма (`src/components/BookingForm.jsx`) збирає: ім’я, телефон, e-mail, тип і дату події, локацію,
кількість гостей, обрані ігри та коментар, і показує екран «Дякуємо!».

- Щоб заявки приходили на Gmail без участі відвідувача, створіть ендпоінт у Formspree / Web3Forms
  (або Google Apps Script) і вкажіть його у `.env`:
  ```
  VITE_FORM_ENDPOINT=https://formspree.io/f/xxxxxxx
  ```
- Без цієї змінної форма відкриває поштовий застосунок відвідувача з уже заповненим листом на `company.email`.
